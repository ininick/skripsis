## PERUBAHAN #1: INCREASE MAX_LENGTH (PALING PENTING!)

```python

```

**SESUDAH:**
```python
MAX_LENGTH = 512  # BERT max length
```

**KENAPA DIUBAH?**
- Artikel politik Indonesia rata-rata punya 1500-2500 karakter
- 1500 chars ≈ 350-450 tokens (bahasa Indonesia)
- Dengan max_length=256, kamu KEHILANGAN 40-60% konten artikel!
- Bagian kesimpulan artikel (yang penting untuk sentiment) sering terpotong

**CONTOH:**
```

[isi artikel panjang]
...kebijakan ini diperkirakan akan berdampak POSITIF pada ekonomi Indonesia."

Dengan max_length=256:
"Jakarta, CNBC Indonesia - Presiden Jokowi mengumumkan kebijakan baru..."
(POTONG DI SINI - KEHILANGAN KESIMPULAN!)
→ Model tidak baca "berdampak POSITIF" → salah prediksi!

Dengan max_length=512:
Full article termasuk kesimpulan → prediksi benar!
```

**EXPECTED IMPROVEMENT:**
- Accuracy: +5-10%
- Macro F1: +8-12%

**BIAYA:**
- Training lebih lambat ~30% (masih acceptable)
- Memory usage naik (tapi dengan batch size adjustment, aman)

## PERUBAHAN #2: TAMBAH CLASS WEIGHTS

**SEBELUM:**
```python
# Tidak ada class weights
trainer = Trainer(...)
```

**SESUDAH:**
```python
# Hitung class weights
from sklearn.utils.class_weight import compute_class_weight

class_weights = compute_class_weight(
    'balanced',
    classes=np.unique(train_df['label_id']),
    y=train_df['label_id'].values
)

# Custom Trainer dengan weighted loss
class WeightedTrainer(Trainer):
    def compute_loss(self, model, inputs, return_outputs=False):
        labels = inputs.pop("labels")
        outputs = model(**inputs)
        logits = outputs.logits
        
        # Weighted CrossEntropyLoss
        loss_fct = torch.nn.CrossEntropyLoss(
            weight=torch.tensor(class_weights, dtype=torch.float).to(device)
        )
        loss = loss_fct(logits, labels)
        
        return (loss, outputs) if return_outputs else loss

# Pakai WeightedTrainer
trainer = WeightedTrainer(
    class_weights=class_weights_tensor,
    ...
)
```

**KENAPA DIUBAH?**
- Data kamu IMBALANCED:
  - Neutral: 559 (70%)  ← Mayoritas!
  - Positive: 125 (15.6%)
  - Negative: 112 (14%)
  
- Tanpa class weights:
  - Model belajar: "Kebanyakan artikel = neutral"
  - Model jadi bias: prediksi neutral terus
  - Accuracy tinggi (70%) tapi F1 rendah!
  
- Dengan class weights:
  - Model dipaksa belajar semua kelas secara equal
  - Prediksi lebih balanced
  - F1 score naik signifikan!

**EXPECTED IMPROVEMENT:**
- F1 (Negative): +15-20%
- F1 (Positive): +15-20%
- Macro F1: +5-7%

## PERUBAHAN #3: OPTIMIZE BATCH SIZE + GRADIENT ACCUMULATION

**SEBELUM:**
```python
per_device_train_batch_size=16,
per_device_eval_batch_size=16,
```

**SESUDAH:**
```python
per_device_train_batch_size=8,       # Lebih kecil
per_device_eval_batch_size=8,        # Lebih kecil
gradient_accumulation_steps=2,       # Akumulasi gradient
```

**KENAPA DIUBAH?**
- Dengan max_length=512, batch_size=16 bisa Out of Memory (OOM)!
- Memory usage: max_length × batch_size × model_size
  - 512 × 16 = 8192 (HUGE!)
  - 512 × 8 = 4096 (safer)
  
- Gradient accumulation:
  - Effective batch size tetap sama: 8 × 2 = 16
  - Tapi memory usage lebih rendah
  - Training lebih stable

**BENEFIT:**
- No Out of Memory error
- Stable training
- Same effective batch size (convergence sama)

## PERUBAHAN #4: TAMBAH LEARNING RATE SCHEDULER

**SEBELUM:**
```python
training_args = TrainingArguments(
    learning_rate=2e-5,
    # Tidak ada scheduler
)
```

**SESUDAH:**
```python
training_args = TrainingArguments(
    learning_rate=2e-5,
    lr_scheduler_type="linear",  # Linear decay
    warmup_ratio=0.1,            # 10% warmup
)
```

**KENAPA DIUBAH?**
- Learning rate constant → bisa stuck di local minimum
- Linear decay:
  - Awal: LR tinggi → explore
  - Akhir: LR rendah → fine-tune
  - Better convergence!
  
- Warmup:
  - 10% pertama: LR naik gradually dari 0 → 2e-5
  - Prevents early divergence
  - Standard practice untuk BERT fine-tuning

**EXPECTED IMPROVEMENT:**
- Better convergence
- Lower final loss
- +2-4% accuracy

```python
import random
import torch

def set_seed(seed=42):
```


**SESUDAH:**
```python
def compute_metrics(eval_pred):
    logits, labels = eval_pred
    preds = np.argmax(logits, axis=1)
    
    report = classification_report(
        labels, preds,
        output_dict=True,
        zero_division=0
    )
    
    return {
        "accuracy": (preds == labels).mean(),
        "macro_f1": report["macro avg"]["f1-score"],
        "weighted_f1": report["weighted avg"]["f1-score"],
        # Per-class F1 scores
        "f1_negative": report.get("0", {}).get("f1-score", 0.0),
        "f1_neutral": report.get("1", {}).get("f1-score", 0.0),
        "f1_positive": report.get("2", {}).get("f1-score", 0.0)
    }
```

**KENAPA DIUBAH?**
- Lebih detail monitoring per-class performance
- Bisa lihat apakah minority classes improve
- Bagus untuk analysis di thesis
